# 猜想 4 · 数独循环 Transformer 的分区门控实验

**状态：当前方案结题，暂时搁置。** 研究问题是把 96 维残差状态的前 32 维设为受门控的写入区，其余 64 维允许自由更新，能否在加深推理时同时保住正确答案和纠正错误。两种门控模型均有 82,697 个参数。比较对象 `full_gate` 将同样数量的门值分组应用到全部 96 个通道。

在固定的 512 道难题上，十个种子中有八个的分区门控较少把正确答案改错，也有八个的最终纠错率较低。这个实现没有达到兼顾两者的目标。结论限于本次数独任务、通道划分和训练协议。[十种子结题报告](sudoku_10seeds/sudoku_10seeds_report.md)

## 难题上的配对结果

每个模型训练 5,000 步，训练时循环 8 轮，测试时展开至第 32 轮。逐格指标在同一训练种子、同一题、同一原始空格上配对，各种子等权。差值为分区减全通道，区间单位为百分点。

| 指标 | 分区门控 | 全通道门控 | 差值 | 固定题目、重采样种子的 95% 区间 | 同时重采样种子和整题的 95% 区间 |
|---|---:|---:|---:|---:|---:|
| 第 8 轮都对，随后曾经改错 | 5.10% | 5.51% | −0.40 | [−0.74, −0.09] | [−0.86, +0.04] |
| 第 8 轮都错，第 32 轮已经改对 | 27.98% | 30.08% | −2.11 | [−3.47, −0.88] | [−4.32, +0.08] |
| 第 32 轮整盘解出 | 41.64% | 43.32% | −1.68 | [−3.79, +0.16] | [−4.71, +1.17] |

表中区间来自 100,000 次重采样。预设的 4,000 次联合重采样给出的最终纠错差区间上限为 −0.005 个百分点，增加至 100,000 次后为 +0.075。对新题的推断接近零边界。单看新增七个种子，五个较少改错，平均差 −0.32 个百分点。六个最终纠错率较低，平均差 −2.74 个百分点。这七个种子仍使用同一批测试题。[逐种子指标](sudoku_10seeds/sudoku_10seeds_metrics.csv) · [区间精度复核](sudoku_10seeds/sudoku_10seeds_precision_check.json)

按第 32 轮统一结算，原先双方都答对的格子中分区门控多保住 312 个，原先都答错的少修好 749 个，原先仅一方答对的合计少答对 215 个。在全部 247,670 个“种子 × 原始空格”上，分区门控最终少答对 **652 格**，在 5,120 个“种子 × 题目”上少解出 **86 盘**。原结题意见中的 699 统计曾经改错的格数差。该意见亦提出共享归一化及读写路径可能影响性能，目前缺少直接的机理测量。[原结题意见](sudoku_split_gate_opinion.md) · [逐轮预测](sudoku_10seeds/sudoku_10seeds_predictions.npz)

## 离线复算

在已安装 NumPy 的 Python 环境中，从仓库根目录执行下列命令。脚本直接读取题面、唯一解及逐格预测，在 CPU 上复算两套题全部十个种子的配对指标。默认使用 4,000 次重采样，将参数改为 `--bootstrap-samples 100000` 可复核上表区间。

```bash
python sudoku_10seeds/sudoku_10seeds_analysis.py sudoku_10seeds/sudoku_10seeds_predictions.npz --output recomputed.json
```
